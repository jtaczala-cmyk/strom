Ingen informasjonskapsler

Spillet bruker ingen informasjonskapsler (cookies) og ingen analyseverktøy.

Data blir på enheten din

Navn, resultater (poeng og KO), rekord og innstillinger (f.eks. lyd) lagres bare i nettleserens lagring (localStorage) på enheten din. Spillfilene lagres også i nettleserens hurtigbuffer, slik at spillet virker uten nett.

Ingenting sendes til utvikleren

Spillet sender ingen data til utvikleren. Topplisten viser bare resultater som er lagret på denne enheten.

Hosting

Spillet ligger på GitHub Pages (GitHub, Inc.). Når sidene lastes, kan GitHub logge IP-adressen din og tekniske data om nettleseren, som beskrevet i GitHubs personvernerklæring. Skriftene ligger sammen med spillet; det kobles ikke til Google Fonts.

Slette data

Du kan når som helst slette disse dataene ved å tømme nettstedsdata for denne siden i nettleserinnstillingene.
